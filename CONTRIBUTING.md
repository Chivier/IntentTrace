# Contributing

IntentTrace is currently private and `UNLICENSED`. Changes should be small, evidence-backed, and scoped to one construction gate.

1. Read `AGENTS.md` and the relevant Accepted ADRs.
2. Update schema, migration, API, documentation, fixtures, and tests together when a contract changes.
3. Do not add provider egress before the security gate is accepted.
4. Run the repository checks listed in `AGENTS.md`.
5. Update `docs/project/progress.md` with commands and results; do not describe planned or static work as runtime verification.
